# AI_Powered_demand_Forecasting_And_Energy_Theft_Detection_In_Smart_Grids


##  Overview

This project focuses on building an intelligent system for **electricity demand forecasting** and **energy theft detection** using Machine Learning techniques. It helps improve efficiency, reduce losses, and enable smarter energy management in smart grids.

---

##  Objectives

* Predict electricity demand using historical data
* Detect anomalies indicating possible energy theft
* Improve grid efficiency and reduce operational losses

---

##  Technologies Used

* Python
* Machine Learning (Scikit-learn)
* Pandas, NumPy
* Matplotlib, Seaborn
* Jupyter Notebook

---

##  Features

*  Demand Forecasting Model
*  Energy Theft Detection System
*  Data Visualization & Analysis
* Performance Evaluation Metrics
